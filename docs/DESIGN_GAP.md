## 總結

### 未實作項目（❌）

1. **商品詳情**：4 張縮圖列、「您可能也會喜歡」相關商品區塊
2. **購物車**：折扣行
3. **結帳**：聯絡電話欄位、訂單備註欄位、折扣行
4. **登入 / 404**：頁面專用 Nav（設計稿無標準 Nav，實際多了一層）
5. **我的訂單**：側欄用戶頭像、用戶姓名/Email、帳戶設定連結、收件地址連結、訂單商品摘要文字
6. **訂單詳情**：商品小計行、查詢付款狀態按鈕、前往付款按鈕、付款方式欄位

### 設計差異（⚠️）

- **所有頁面**：設計稿中登入、404、購物車、結帳、訂單等頁面均**無完整 Footer**，實際實作皆加入完整 3 欄 Footer + Footer Bar
- **商品詳情**：設計僅有簡化版 Footer Bar，實際是完整 Footer
- **我的訂單**：Nav 顯示「Admin」而非用戶真實姓名
